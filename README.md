# python-jupyter-notebook-practice

## 📌 Project Overview

This project contains five Python Jupyter Notebook files created as part of Python programming practice.

The main purpose of this project is to understand and practice basic Python built-in functions such as:

- `print()`
- `id()`
- `type()`

Each notebook contains at least three code cells demonstrating these functions with different types of data.
